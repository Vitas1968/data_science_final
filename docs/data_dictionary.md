# Data Dictionary

## ga_sessions (уровень визита)

| Колонка | Что это значит | Польза для бизнеса |
|---------|----------------|--------------------|
| session_id | Уникальный ID визита | Связка с событиями (ga_hits), ключ анализа |
| client_id | ID клиента | Можно считать число уникальных клиентов, повторные визиты |
| visit_date | Дата визита | Анализ по времени (дни, недели, тренды) |
| visit_time | Время визита | Почасовой анализ, пики активности |
| visit_number | Номер визита у клиента | Понимание воронки: с какого визита конверсия |
| utm_source | Источник (Google, Yandex, VK …) | Оценка эффективности каналов |
| utm_medium | Тип трафика (cpc, organic, referral …) | Сравнение платного / органического / соцсетей |
| utm_campaign | Название кампании | ROI конкретных рекламных кампаний |
| utm_keyword | Ключевое слово | Эффективность семантики |
| utm_adcontent | Креатив (вариант объявления) | A/B-тесты рекламных материалов |
| device_category | Категория устройства | Desktop / Mobile / Tablet → поведение отличается |
| device_os | ОС | Популярность платформ (Windows, Android, iOS …) |
| device_brand | Бренд устройства | Косвенно сегменты пользователей |
| device_model | Модель | Почти пусто → можно игнорировать |
| device_screen_resolution | Разрешение экрана | Юзабилити, адаптивность сайта |
| device_browser | Браузер | Техническая оптимизация (Chrome, Safari …) |
| geo_country | Страна | География аудитории |
| geo_city | Город | Региональная аналитика |

---

## ga_hits (уровень действия внутри визита)

| Колонка | Что это значит | Польза для бизнеса |
|---------|----------------|--------------------|
| session_id | ID визита | Связка с ga_sessions |
| hit_date | Дата события | Синхронизация с визитом |
| hit_time | Время (секунды от начала визита) | Сколько времени прошло до события |
| hit_number | Порядок события в визите | Последовательность шагов (воронка) |
| hit_type | Тип события (pageview, event) | Разделение просмотров страниц и кликов |
| hit_referer | Источник перехода | Откуда пришёл на страницу |
| hit_page_path | URL страницы | Какие страницы смотрели чаще всего |
| event_category | Категория события | Группировка действий |
| event_action | Конкретное действие | Определение целевых событий |
| event_label | Доп. описание события | Контекст (например, название кнопки) |
| event_value | Числовое значение | У нас всегда пустое, не используется |

---

## Ключи и связь таблиц

- `session_id` связывает визит (ga_sessions) и события (ga_hits).  
- `ga_sessions` отвечает на вопрос: **Кто, откуда и с чем пришёл**.  
- `ga_hits` отвечает на вопрос: **Что делал на сайте**.

---

## Целевые события (event_action → target=1)

Ниже перечислены события, которые считаются целевыми и формируют метку `target=1`:

- `sub_car_claim_click` — клик по кнопке "Оставить заявку".
- `sub_car_claim_submit_click` — отправка формы заявки.
- `sub_open_dialog_click` — открытие диалога/чата.
- `sub_custom_question_submit_click` — отправка кастомного вопроса.
- `sub_call_number_click` — клик по номеру телефона.
- `sub_callback_submit_click` — заявка на обратный звонок.
- `sub_submit_success` — успешная отправка формы.
- `sub_car_request_submit_click` — отправка запроса на автомобиль.
